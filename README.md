# ATracker readme

ATracker is a Python package dedicated to tracking individuals and groups of animals in a user-friendly way. It relies heavily on opencv and works on both Mac, Windows, and Linux systems. It is developed and actively maintained by Jolle Jolles, senior researcher at CEAB-CSIC. To learn how to set up, install, and use atracker, navigate to the documentation folder!

**Note**: ATracker is still being actively developed and uses many packages that are themselves constantly being updated. Therefore to keep ATracker working properly we use a specific older stable version of Python (Python 3.9) and package versions (see `setup.py`) such that everything works out of the box.
